# Bug log: observations, verification and the learned forecast

Started 14 October 2026. One row per bug, newest first. Add a row when a bug is found, even if it is fixed straight away, so patterns are visible later.

**How bugs get here**

- **Automatic:** the daily learning job runs health checks (`src/mcp/learning-health.ts`). A problem opens a GitHub issue labelled `learning-health`, later problems are added as comments, and the issue closes itself once every check passes. When an issue reveals a real bug, record it here and link the issue.
- **Manual:** anything found in testing, review or use.

**Fields:** ID, date found, area, severity (high: wrong values shown to users; medium: wrong values in a tool, report or backtest, or a failure; low: cost, speed or cosmetic), what went wrong, the cause, the fix, status, where it was fixed, and how it was found.
